# How to run?

# change dir
```
cd host-app or 'root project'
cd auth
```
# run dev
```
host-app> npm run dev
auth> npm run dev
...
```

# run build & run
```
host-app> npm run build & npm run start
auth> npm run build & npm run start
...
```
