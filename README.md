# How to run?

# change dir
```
cd host-app
cd auth
... tương tự các service khác ...
```
# run dev
```
host-app> npm run dev
auth> npm run dev
... tương tự các service khác ...
```

# run build & run
```
host-app> npm run build & npm run start
auth> npm run build & npm run start
...
```
